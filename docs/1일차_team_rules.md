# Pneumonia Backoffice Project Rules

## 개인 프로젝트 규칙

### 1. 1일 1커밋
매일 작업한 내용을 확인하고 커밋한다.

### 2. 작업 내용 기록
완료한 작업과 발생한 오류를 기록한다.

### 3. 실행 확인
작성한 코드가 정상적으로 실행되는지 확인한 후 업로드한다.

### 4. 민감한 정보 보호
비밀번호, API Key, 개인정보는 GitHub에 올리지 않는다.

## Git & GitHub Rules

### 1. 명확한 커밋 메시지 작성
수정한 내용을 알아볼 수 있도록 커밋 메시지를 작성한다.

### 2. Push 전 변경 내용 확인
GitHub에 올리기 전에 수정한 파일을 확인한다.

### 3. main 브랜치 관리
오류가 있거나 완료되지 않은 코드는 main 브랜치에 올리지 않는다.
